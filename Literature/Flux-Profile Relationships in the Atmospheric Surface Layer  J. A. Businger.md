# Businger et al. (1971) — Flux-Profile Relationships in the Atmospheric Surface Layer

## Aim of the paper

The paper investigates how **wind speed**, **temperature**, **surface momentum flux**, and **surface heat flux** are related inside the **atmospheric surface layer**.

The analysis is based on measurements from the **1968 Kansas field experiment**.

The main purpose is to test **Monin–Obukhov Similarity Theory (MOST)** using experimental data obtained over a relatively flat and horizontally homogeneous surface.

The authors measure both:

**vertical wind and temperature profiles**

and:

**turbulent momentum and heat fluxes**

This makes it possible to test whether the similarity relationships correctly describe the actual atmospheric surface layer. 

---

# Atmospheric Surface Layer

The atmospheric surface layer is the lowest part of the Atmospheric Boundary Layer.

In this region, the dominant turbulent processes are the vertical transport of:

**momentum**

and:

**heat**

For an approximately horizontally homogeneous surface, these turbulent fluxes are assumed to vary only weakly with height.

This allows the vertical profiles of wind and temperature to be described using a small number of characteristic quantities.

---

# Monin–Obukhov Similarity Theory

MOST describes surface-layer turbulence using dimensionless variables.

The main stability parameter is:

```math
\zeta=\frac{z}{L}
```

where:

**z** = height above the ground

**L** = Monin–Obukhov length

The value of `z/L` indicates the atmospheric stability.

### Unstable conditions

```math
\frac{z}{L}<0
```

Buoyancy promotes vertical motion and turbulence.

### Neutral conditions

```math
\frac{z}{L}=0
```

Buoyancy has little effect and turbulence is mainly generated by wind shear.

### Stable conditions

```math
\frac{z}{L}>0
```

Buoyancy suppresses vertical motion and turbulent mixing.

---

# Main Variables

**U** = mean horizontal wind speed

**θ** = potential temperature

**z** = height above the ground

**z₀** = aerodynamic roughness length

**u*** = friction velocity

**θ*** = temperature scale

**κ** = von Kármán constant

**L** = Monin–Obukhov length

**Ri** = gradient Richardson number

**φm** = dimensionless wind-gradient function

**φh** = dimensionless temperature-gradient function

**Km** = turbulent diffusivity for momentum

**Kh** = turbulent diffusivity for heat

---

# Friction Velocity

The friction velocity is related to the surface shear stress:

```math
u_*=\sqrt{\frac{\tau}{\rho}}
```

where:

**τ** = turbulent shear stress

**ρ** = air density

The friction velocity is not simply a wind speed.

It represents the strength of the turbulent transfer of horizontal momentum between the ground and the atmosphere.

Therefore:

**surface stress increases → friction velocity increases**

---

# Dimensionless Wind Gradient

The wind similarity function is defined as:

```math
\phi_m=\frac{\kappa z}{u_*}\frac{\partial U}{\partial z}
```

The term:

```math
\frac{\partial U}{\partial z}
```

represents the vertical wind-speed gradient.

The function `φm` describes how atmospheric stability changes this gradient.

Therefore:

**stability → φm → wind-speed gradient**

Under neutral conditions:

```math
\phi_m\approx1
```

---

# Dimensionless Temperature Gradient

The corresponding temperature similarity function is:

```math
\phi_h=\frac{z}{\theta_*}\frac{\partial\theta}{\partial z}
```

where:

```math
\frac{\partial\theta}{\partial z}
```

is the vertical gradient of potential temperature.

Therefore:

**φm → momentum transport**

**φh → heat transport**

The paper determines how both functions vary with atmospheric stability. 

---

# The Kansas Experiment

The measurements were collected during the summer of **1968** over a flat agricultural site in Kansas.

A tower about:

```math
32\text{ m}
```

high was used.

Wind speed was measured at several heights between approximately:

```math
2\text{ m}
```

and:

```math
32\text{ m}
```

Temperature was also measured at several vertical levels.

Turbulent fluctuations of velocity and temperature were measured using fast-response instruments.

These measurements allowed the researchers to calculate:

**momentum flux**

and:

**heat flux**

directly.

The analysis uses **34 experimental runs**, normally based on 15-minute average periods. 

---

# Why the Flux Measurements Are Important

A wind or temperature profile alone does not directly tell us whether a surface-layer model is correct.

The important test is whether the profile relationships predict the same turbulent fluxes that are actually measured.

Therefore the experiment provides:

**measured profiles**

*

**measured turbulent fluxes**

This makes it possible to compare the predictions of MOST against independent measurements.

---

# von Kármán Constant

The von Kármán constant appears in the logarithmic wind law and in the similarity functions.

A commonly used value is:

```math
\kappa\approx0.40
```

The Kansas data, however, indicate a lower value of approximately:

```math
\boxed{\kappa\approx0.35}
```

The value of `κ` is important because it directly influences the calculation of friction velocity and wind gradients. 

---

# Unstable Conditions

For unstable stratification:

```math
\frac{z}{L}<0
```

Surface heating promotes buoyancy and vertical turbulent mixing.

The authors determine empirical functions describing how wind and temperature gradients change under these conditions.

---

# Unstable Momentum Function

For momentum, a good representation of the measurements is:

```math
\phi_m=\left(1-15\frac{z}{L}\right)^{-1/4}
```

The constant:

```math
15
```

comes from fitting the function to the atmospheric measurements.

Because:

```math
\frac{z}{L}<0
```

the quantity inside the brackets is greater than one.

Therefore:

```math
\phi_m<1
```

for unstable conditions.

Physical meaning:

**stronger buoyancy → stronger mixing → smaller wind gradient needed to transport momentum**

---

# Unstable Temperature Function

For heat, the paper obtains:

```math
\phi_h=0.74\left(1-9\frac{z}{L}\right)^{-1/2}
```

Two important constants appear:

```math
0.74
```

and:

```math
9
```

The value `0.74` represents the approximate neutral value of the dimensionless temperature gradient.

The value `9` controls how the temperature gradient changes with unstable stratification.

The momentum and heat functions therefore do not have exactly the same stability dependence.

---

# Stable Conditions

For stable stratification:

```math
\frac{z}{L}>0
```

Buoyancy suppresses vertical motion.

Turbulent mixing becomes weaker.

As a result, stronger vertical gradients of wind and temperature are required to transport momentum and heat.

---

# Stable Momentum Function

The measured wind-gradient behaviour is approximately linear:

```math
\phi_m=1+4.7\frac{z}{L}
```

Therefore:

**stability increases → φm increases → wind gradient increases**

The constant:

```math
4.7
```

is obtained empirically from the measurements.

---

# Stable Temperature Function

For temperature:

```math
\phi_h=0.74+4.7\frac{z}{L}
```

Again, the value at neutral conditions is approximately:

```math
\phi_h(0)=0.74
```

and the stable correction uses a slope of approximately:

```math
4.7
```

The stable momentum and temperature relationships agree reasonably well with the field observations. 

---

# Near-Neutral Conditions

Very close to neutral stability, the experimental data show that the transition is not perfectly linear.

For momentum, the paper gives an approximate quadratic relation:

```math
\phi_m=1+3.0\zeta+10.2\zeta^2
```

For temperature:

```math
\phi_h=0.74+3.0\zeta+9.2\zeta^2
```

with:

```math
\zeta=\frac{z}{L}
```

These expressions describe the detailed behaviour close to:

```math
\zeta=0
```

For the main interpretation of the paper, the stable and unstable formulas are more important.

---

# Turbulent Diffusivity

Turbulence transports both momentum and heat.

The paper describes this using two turbulent diffusivities.

**Km** = turbulent diffusivity for momentum

**Kh** = turbulent diffusivity for heat

The ratio is:

```math
\alpha=\frac{K_h}{K_m}
```

This quantity tells us whether turbulence transports heat and momentum with the same efficiency.

---

# Relation Between α and the Similarity Functions

The paper obtains:

```math
\alpha=\frac{\phi_m}{\phi_h}
```

At neutral conditions:

```math
\phi_m\approx1
```

and:

```math
\phi_h\approx0.74
```

Therefore:

```math
\alpha\approx\frac{1}{0.74}
```

which gives:

```math
\boxed{\alpha\approx1.35}
```

This means that under neutral conditions:

```math
K_h>K_m
```

According to these measurements, turbulence transports heat somewhat more effectively than momentum.

---

# Variation of α with Stability

The ratio `α` is not constant.

Under unstable conditions:

**α increases as instability increases**

Under stable conditions:

**α decreases**

For increasingly stable conditions:

```math
\alpha\rightarrow1
```

This means that the relative efficiency of turbulent heat and momentum transport changes with atmospheric stability.

The experimental dependence is shown in the paper's plot of `α` against `z/L`. 

---

# Turbulent Prandtl Number

The turbulent Prandtl number describes the relative turbulent transport of momentum and heat.

It can be written as:

```math
Pr_t=\frac{K_m}{K_h}
```

Since:

```math
\alpha=\frac{K_h}{K_m}
```

then:

```math
Pr_t=\frac{1}{\alpha}
```

For neutral conditions:

```math
\alpha\approx1.35
```

therefore:

```math
Pr_t\approx0.74
```

So the value:

```math
\boxed{Pr_t\approx0.74}
```

is associated with the neutral atmospheric surface layer in this experiment.

---

# Gradient Richardson Number

The **gradient Richardson number** compares the influence of buoyancy with the influence of wind shear.

```math
Ri=
\frac{
\frac{g}{\theta}
\frac{\partial\theta}{\partial z}
}{
\left(\frac{\partial U}{\partial z}\right)^2
}
```

Conceptually:

```math
Ri\sim\frac{\text{buoyancy}}{\text{wind shear}}
```

### Unstable conditions

```math
Ri<0
```

Buoyancy promotes turbulence.

### Stable conditions

```math
Ri>0
```

Buoyancy suppresses turbulence.

---

# Relation Between Ri and z/L

The paper investigates the relationship between two stability parameters:

```math
Ri
```

and:

```math
\frac{z}{L}
```

Close to neutral conditions:

```math
Ri\approx0.74\frac{z}{L}
```

They therefore describe similar physical behaviour but are not exactly the same quantity.

---

# Critical Richardson Number

For increasingly stable conditions, the measured Richardson number approaches approximately:

```math
\boxed{Ri\approx0.21}
```

The paper interprets this value as a possible **critical Richardson number**.

As stability becomes stronger:

**buoyancy suppression increases**

↓

**vertical turbulent mixing decreases**

↓

**turbulence becomes weaker**

The value around `0.21` represents the limiting behaviour observed in the measurements. 

---

# Calculating Fluxes from Profiles

The authors also test whether the wind and temperature profile equations can be used to estimate turbulent fluxes.

From the measured profiles, they calculate quantities such as:

**friction velocity**

and:

**surface heat flux**

These calculated values are then compared with the fluxes measured directly by the instruments.

The agreement is generally good.

Therefore:

**profile relationships → calculated fluxes**

agree reasonably well with:

**directly measured fluxes**

This provides experimental support for using the similarity relationships to describe the atmospheric surface layer. 

---

# Main Results

The main conclusion is that the Kansas measurements support the predictions of **Monin–Obukhov Similarity Theory**.

The most important empirical relationships are:

## Unstable momentum

```math
\boxed{\phi_m=\left(1-15\frac{z}{L}\right)^{-1/4}}
```

## Unstable heat

```math
\boxed{\phi_h=0.74\left(1-9\frac{z}{L}\right)^{-1/2}}
```

## Stable momentum

```math
\boxed{\phi_m=1+4.7\frac{z}{L}}
```

## Stable heat

```math
\boxed{\phi_h=0.74+4.7\frac{z}{L}}
```

The experiment also suggests:

```math
\boxed{\kappa\approx0.35}
```

and, under neutral conditions:

```math
\boxed{\alpha\approx1.35}
```

The profile-derived turbulent fluxes agree reasonably well with the directly measured fluxes over the range of stability conditions studied.
